# Eugênio Neto - Portfolio Website
## ACESSE: https://netoeugenio.github.io/

Portfólio profissional moderno e responsivo para Analista de Dados & Junior Data Engineer, com foco em análise exploratória, visualização e engenharia de dados.

## 🎯 Sobre o Projeto

Este é um portfólio estático desenvolvido com HTML5 e CSS3 puro, focado em apresentar projetos e habilidades em Análise de Dados e Engenharia de Dados - com destaque para EDA, visualização, dashboards e pipelines ETL/ELT.

## ✨ Características

- **Design Moderno e Profissional**: Interface limpa e elegante focada em recrutadores
- **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Performance Otimizada**: Carregamento rápido sem dependências pesadas
- **SEO Friendly**: Meta tags e estrutura semântica otimizada
- **Acessibilidade**: Seguindo boas práticas de acessibilidade web
